# Human Design Transit Archive

A dedicated research archive and dataset for the **Human Design System**, tracking exact historical gate and line transitions, direct/retrograde states, and precise ISO-8601 UTC timestamps for outer planets and lunar nodes from 1781 through 2025.

## Purpose & Scope

This repository is curated strictly for **research, data analysis, and computational modeling** within the Human Design System. It provides long-term ephemeris data for slow-moving celestial bodies (Uranus, Neptune, Pluto) and the North Node, enabling deep historical study of global conditioning shifts, transit cycles, and evolutionary epoch markers.

## Dataset Files

* `neptune_1781_2025.txt` — Neptune transit records (1781–2025)
* `pluto_1781_2025.txt` — Pluto transit records (1781–2025)
* `uranus_1781_2025.txt` — Uranus transit records (1781–2025)
* `nodes_1781_2025.txt` — North Node transit records (1781–2025)

## Data Format

Each record maps a precise UTC timestamp to a Human Design gate, line number, and motion state (direct or retrograde):

```text
1781-05-28T09:59:47.873881+00:00  -->  Gate 12, Line 6 (direct)
1781-06-13T09:44:04.593340+00:00  -->  Gate 15, Line 1 (direct)
1781-11-24T11:44:28.036678+00:00  -->  Gate 15, Line 4 (retrograde)
